# src

## Overview
Application source for the Vite + React web app. `main.tsx` is the entry point and creates the TanStack router from the generated route tree.

## Interface
- `main.tsx`: creates `router` with `createRouter({ routeTree, defaultPreload: "intent", scrollRestoration: true, defaultPendingComponent: () => <Loader />, context: {} })`, registers it via `declare module "@tanstack/react-router" { interface Register }`, and renders `RouterProvider` into `#app`.
- `index.css`: imports `@project-vayu/ui/globals.css`.
- `env.ts` (generated by varlock via `.env.schema` `@generateTsTypes`, gitignored via `apps/web/.gitignore`): exports typed `ENV` with `NODE_ENV` and `VITE_SERVER_URL`. Do not edit.
- `routeTree.gen.ts` (generated by TanStack Router, gitignored via the root `.gitignore`): exports `routeTree`. Do not edit.
- Subdirectories: [components](./components/README.md), [lib](./lib/README.md), [routes](./routes/README.md).

## Invariants
- `main.tsx` throws `Error("Root element not found")` if `#app` is missing, and renders only when `rootElement.innerHTML` is empty.
- `env.ts` and `routeTree.gen.ts` are overwritten by tooling (`pnpm --filter web env:generate`, and the Vite router plugin respectively); change `.env.schema` or the files in `routes/` instead.

## Side Effects
- `main.tsx` mounts a React root on the DOM element `#app`.

## Verification
- Run: `pnpm --filter web check-types` (no test runner is configured).
