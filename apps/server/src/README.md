# src

## Overview
Entry point and wiring of the `server` Fastify app: process startup, environment access, the SQLite store, and the route and domain subdirectories.

## Interface
- `index.ts` - server entry (no exports). Configures CORS and evlog, registers `briefRoutes`, defines `GET /` returning `"OK"`, and listens on port 8080.
- `services.ts:store` - shared store instance, `openStore(ENV.DATABASE_URL)`.
- `store.ts:openStore(databaseUrl): Store` returning `{ insert, update, get, latest, close }`; `store.ts:Store` type.
  - `insert(brief: Omit<Brief, "id">): Brief`, `update(brief)`, `get(id): Brief | null`, `latest(): Brief | null`, `close()`.
- `env.server.ts` - imports `varlock/auto-load` and re-exports `ENV` from `./env`.
- `env.ts` - generated by varlock (`pnpm --filter server env:generate`, i.e. `varlock codegen`); marked "AUTOGENERATED - DO NOT EDIT" and gitignored via `/src/env.ts` in `../.gitignore`. It types `ENV` (includes `NODE_ENV`, `CORS_ORIGIN`, `DATABASE_URL`, `OPENROUTER_API_KEY`, `OPENROUTER_MODEL`).
- Subdirectories:
  - [./brief/README.md](./brief/README.md) - parsing, analysis, comparison, LLM writing.
  - [./routes/README.md](./routes/README.md) - HTTP route plugins.

## Invariants
- `store.ts:openStore` keeps each brief whole as JSON in `briefs.data`; separate columns are `id`, `created_at`, `audience`. `file:` prefix is stripped from the URL; `:memory:` is allowed, other paths resolve against `process.cwd()`.
- `store.ts:insert` writes a placeholder `"{}"` row and then updates it so the stored JSON contains the generated `id`.
- `store.ts:latest` orders by `id DESC` (latest means highest id).
- `index.ts` uses `ENV.CORS_ORIGIN` for CORS origin with methods GET, POST, PUT, DELETE, OPTIONS; the port is hard-coded to 8080.
- `index.ts` evlog drain is `createFsDrain()` unless `process.env.NODE_ENV === "production"`.
- `env.ts` must not be edited by hand; regenerate it instead.

## Side Effects
- `store.ts:openStore` creates the database directory (`mkdirSync`), opens a `node:sqlite` `DatabaseSync`, runs `PRAGMA journal_mode = WAL` and `CREATE TABLE IF NOT EXISTS briefs`.
- `services.ts` opens the database at import time.
- `index.ts` starts an HTTP listener on port 8080, calls `initLogger` (service `project-vayu-server`), and exits with code 1 if listening fails; in non-production the fs drain writes logs to disk (`.evlog/` appears under the app directory).
- `env.server.ts` loads environment values through varlock at import time.
