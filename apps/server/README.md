# server Blueprint

## System Overview
`server` is the Fastify HTTP backend (ESM, TypeScript) of project-vayu. It has no source files directly in this directory; all code lives under `src/`. Build tooling is `tsdown` (`tsdown.config.ts`: entry `./src/index.ts`, format `esm`, output `./dist`, bundles `@project-vayu/*` workspace packages). Scripts in `package.json`: `build`, `check-types`, `test` (`tsx --test "src/**/*.test.ts"`), `dev` (`tsx watch src/index.ts`), `start` (`node dist/index.mjs`), `env:generate` (`varlock codegen`). Environment variables are declared in `.env.schema` (`NODE_ENV`, `CORS_ORIGIN`, `DATABASE_URL`, `OPENROUTER_API_KEY`, `OPENROUTER_MODEL`).

## Subdirectories & System Boundaries
- src: [./src/README.md](./src/README.md) - entry point, SQLite store, env wiring; contains the `brief` domain core and `routes` HTTP plugins.

## Global Invariants
- `src/env.ts` is generated by varlock and gitignored; run `pnpm --filter server env:generate` to produce it.
- Briefs are persisted whole as JSON in the SQLite `briefs` table (`src/store.ts`).
- LLM text is accepted only if it passes code checks (`src/brief/write.ts:checkText`); otherwise labelled fallback text is used.

## Global Side Effects
- Listens on port 8080 (`src/index.ts`).
- Reads and writes a local SQLite database at `DATABASE_URL`.
- Calls the OpenRouter API (`src/brief/llm.ts`).
- Non-production runs write evlog files via `createFsDrain()`.

## System Verification
- Run: `pnpm --filter server test`
- Run: `pnpm --filter server check-types`
