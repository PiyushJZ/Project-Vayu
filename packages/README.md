# packages

## Overview

Shared workspace packages consumed by the apps. `ui` holds the shared shadcn/ui components, helpers and global styles. `config` contains only a `package.json` and `tsconfig.base.json` (no source code), so it has no contract file.

## Subdirectories & Boundaries

- ui: [./ui/README.md](./ui/README.md) - `@project-vayu/ui` shared components, `cn` helper and `globals.css`.
