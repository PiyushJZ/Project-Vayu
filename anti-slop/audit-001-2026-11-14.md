## Fix notes for the bigger items

- **1 and 2 together:** give each browser an anonymous owner token: a random id in an `HttpOnly; Secure; SameSite=Strict` cookie, set by the Worker. Store it on each brief, require it on `/write`, and scope `latest()` to it. That closes the read-by-id hole and the cross-user comparison without adding accounts. Briefs that already exist would have no owner and drop out of comparisons. **Alternative:** if this deployment is meant to be one shared team workspace, say so. Then the shared comparison is intended, and the fix becomes "put the deploy behind Cloudflare Access" instead.
- **3:** Cloudflare's Workers rate-limit binding (`ratelimits` in `wrangler.jsonc`), keyed on `CF-Connecting-IP`, on `POST /api/briefs*`, plus Hono's `bodyLimit` at around 1 MB.
- **8:** `apps/web/public/_headers` for the static page and Hono `secureHeaders()` for `/api`. Proposed CSP: `default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data:; font-src 'self'; connect-src 'self'; frame-ancestors 'none'; base-uri 'self'; form-action 'self'`. Inline styles are needed for the station bars.

## What passed (evidence)

- **R-25 contrast**, script-checked. Light: muted on ground 7.94, muted on card 7.18, destructive on card 5.18, button text 5.88, accent on ground 5.15. Dark: muted on ground 8.49, muted on card 7.75, destructive on card 7.77, button text 9.05, muted on popover 7.10. All pass AA.
- **R-32:** one global `:focus-visible` ring, a skip link to `#main`, native buttons, `<details>`/`<summary>`, and a keyboard alternative to drag-and-drop (the file button).
- **R-02:** the only em dashes are data (an empty-cell token in `samples.ts:123` and `table.ts:99`), not copy.
- **R-16, R-17, R-18, R-36, R-38:** no buzzwords, emoji or invented statistics. Sample readings are labeled "invented" in two places.
- **R-24, R-26:** no nav links that go nowhere. Every control has a handler.
- **R-27:** briefs have empty, loading and error states that name the cause and the next step ("Try writing again").
- **R-39 page semantics:** `lang="en"` and `lang="hi"` where Hindi appears, one `h1`, header/main/footer landmarks, zoom allowed.
- **R-40:** the logo has width and height, fonts are self-hosted, and there is no third-party script.
- **A03 injection:** all SQL uses bound parameters. There are no `dangerouslySetInnerHTML` or `innerHTML` sinks, and model output is schema-checked and rendered as text.
- **A06:** `pnpm audit --prod` shows no open advisories (1 low, already reviewed and ignored).
- **A02, A10:** the key is a Worker secret and the e2e key is a stub. The model URL comes from config only, never from the request.
- Router devtools compile to a no-op in production builds.
